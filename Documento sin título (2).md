**62 User Stories**

| Section 1 — Core Mechanics  (Stories \#1 – \#10) |
| :---- |

| User Story \#1   Action Points Starting Pool |  |
| :---- | :---- |
| **As** | player |
| **I want** | start each horde with 5 Action Points (AP) |
| **So that** | have resources available to play cards from my very first turn |
| **Acceptance Criteria** |  |
| **AC1** | Player begins every horde with exactly 5 AP. |
| **AC2** | AP counter is visible in the HUD at all times. |
| **AC3** | AP cannot go below zero. |
| **AC4** | Cards requiring more AP than available are visually disabled. |
| **Priority** | 1  (1 \= highest) |
| **Estimation** | 1 day |

| User Story \#2   AP Carryover Between Turns |  |
| :---- | :---- |
| **As** | player |
| **I want** | accumulate unused AP across turns with no cap |
| **So that** | save resources to deploy powerful multi-card strategies later in the horde |
| **Acceptance Criteria** |  |
| **AC1** | Unspent AP adds to next turn's pool with no upper limit. |
| **AC2** | Saved AP persists until the end of the horde. |
| **AC3** | HUD displays the updated accumulated AP correctly after each turn. |
| **AC4** | AP resets to 5 at the start of the next horde (plus any bonus). |
| **Priority** | 1  (1 \= highest) |
| **Estimation** | 1 day |
